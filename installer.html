Instalar / atualizar Apps Script

O código já está pronto. O Google exige autorização do dono da planilha na primeira instalação; depois o menu Léxis fica disponível dentro da própria planilha.

1

Copie o bridge completo

Clique no botão. Não há token ou senha dentro do código; o segredo fica em Script Properties.

Carregando…

2

Abra o Apps Script da planilha

Na planilha, vá em Extensões → Apps Script. Atualize somente o arquivo do bridge, cole o código copiado e salve. Preserve os demais arquivos e gatilhos do scanner. Se já houver um roteador doPost/doGet, mantenha apenas uma definição de cada, delegando para syncDoPost_/syncDoGet_.

ABRIR PLANILHA
3

Autorize e publique uma vez

  1. No editor, execute ensureSheetsUI uma vez e aceite as permissões do Google.
  2. Abra Configurações do projeto → Propriedades do script e configure LEXIS_SHEETS_TOKEN com o mesmo valor da Vercel.
  3. Para atualizar: Implantar → Gerenciar implantações → Editar → Nova versão → Implantar. Isso mantém a URL. Use Nova implantação apenas na primeira instalação.
  4. Executar como: Eu. Use o mesmo acesso já definido para o bridge e copie a URL /exec para LEXIS_APPS_SCRIPT_URL na Vercel se for a primeira implantação.
✓

Depois fica simples

Depois de publicar, abra o app e clique em Sincronizar. Consulte um processo no scanner e confira Movimentações_DataJud e Publicações_DJEN. Executar ensureSheetsUI confere a estrutura, mas não publica uma nova versão do Web App.
